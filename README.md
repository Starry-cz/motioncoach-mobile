# 动作研习室手机版

选择一份标准示范，再选择一段或多段学生录像。每位学生使用一段独立录像，每段支持 3 秒到 20 分钟。手机本地识别动作，计算总体、身体、左手和右手得分，支持骨架复盘、逐帧对比和 A–B 循环。

| 手机 | 安装入口 | 使用方法 |
| --- | --- | --- |
| 安卓 | [下载 APK](https://starry-cz.github.io/motioncoach-mobile/motioncoach-android.apk) | 用手机浏览器下载，点开 APK 安装。首次打开即可离线分析。 |
| iPhone | [在 Safari 打开](https://starry-cz.github.io/motioncoach-mobile/) | 点「共享」和「添加到主屏幕」。从主屏幕打开，等页面显示「离线可用」。 |

[查看或保存双端二维码安装图](https://starry-cz.github.io/motioncoach-mobile/install-guide.png)

安卓安装后从桌面的「动作研习室」图标打开。界面和姿态模型都在 APK 内，App 使用系统 WebView 运行它们。如果旧版停在「需要更新系统 WebView」，请用 1.1.1 或更新的 APK 覆盖安装。若仍出现「启动诊断」，可按屏幕显示的具体原因和组件版本处理。

如果安装网页暂时打不开，安卓用户也可以[直接从本仓库下载同一份签名 APK](https://github.com/Starry-cz/motioncoach-mobile/raw/refs/heads/main/motioncoach-android.apk)。

视频和练习记录保存在使用者的设备上。从旧网址迁来的 iPhone 用户可在原入口查看之前的记录。

### 在手机上生成 AI 报告

1. 首页点「AI 接口」，选择 DeepSeek 或阿里云百炼（北京），填写对应的 API Key，点「应用设置」。个人手机可勾选「在此设备记住该服务的 Key」。
2. 分析录像后，选中一位学生，点「AI 长评与问答」。可生成教练长评、训练计划，或就具体秒数提问。生成时需要联网，由对应服务账户按用量付费。手机仅发送当前学生的评分、测量和相关问答。
3. 点「导出个人 PDF」保存带已生成反馈的报告。多人练习还可在「全班总览」导出班级评分。下次在「练习记录」里可重新打开。

在「标准库」保存常用示范，在「训练中心」循环练习关键片段、记录轮数，也可比较同一练习者在相同示范下的两次录像。手机型号和拍摄机位会影响测量，比较进步时请尽量保持一致。
